Preloaded KV-Cache Ring

In Cache-Augmented Generation (CAG), your static reference corpus is tokenized and forward-passed once offline. The resulting Key-Value (KV) attention matrices are pinned directly in high-bandwidth GPU HBM memory around the LLM core.

Architectural Advantage

Zero runtime retrieval hops, zero chunking boundary loss, and holistic cross-document attention from Token #1.

Primary Bottleneck

Linearly consumes GPU VRAM per token (~50MB–120MB per 1K tokens depending on model size) and requires cache invalidation when docs change.
